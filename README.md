#  Student Performance Analyzer

A beginner-friendly Python project that analyzes a student's academic performance and generates a formatted performance report.

##  Features

- Calculates average marks
- Assigns a grade based on average marks
- Counts failed subjects
- Determines PASS/FAIL status
- Finds the highest-scoring subject
- Checks for academic warning
- Generates a final student report

##  Concepts Used

- Python Functions
- Lists
- Loops
- Conditional Statements
- Return Values
- Multiple Return Values
- String Formatting

##  How to Run

1. Open `Student_Performance_Analyzer.ipynb`
2. Run the notebook from top to bottom
3. Enter or modify the student data in the data section
4. View the generated performance report
